Heroicx

An open source launcher for GOG, Epic and Amazon games. A fork of Heroic Games Launcher wearing the Quad4 void theme.

Download latest release View source

// features

  • stores GOG, Epic Games Store and Amazon Games libraries in one place
  • wine / proton Run Windows games on Linux and macOS with Wine, Proton or CrossOver
  • themes Quad4 void theme by default, with a light paper variant
  • private No telemetry, no tracking

heroicx is a fork of Heroic Games Launcher. Licensed under GPL-3.0. All credit for the launcher goes to the upstream authors and contributors.
